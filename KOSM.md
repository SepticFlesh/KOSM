# KOSM — Браузерный трёхмерный космический симулятор

## План разработки

---

## 1. Концепция и жанр

**KOSM** — это браузерный космический симулятор с видом от первого/третьего лица, в котором игрок управляет космическим кораблём, исследует открытую вселенную, торгует, сражается и выполняет миссии. Жанровая смесь: *Elite* + *Freelancer* + *No Man's Sky* (в упрощённом, браузерном исполнении).

### Ключевые pillars
- **Свобода перемещения** — бесшовные перелёты между планетами, станциями и звёздными системами
- **Экономика и торговля** — динамические цены, контрабанда, добыча ресурсов
- **Боевая система** — PvE-сражения с пиратами и фракциями, возможность PvP
- **Прогрессия** — прокачка корабля, модули, репутация у фракций
- **Мультиплеер** — общий мир с другими игроками (опционально)

## 2. Технологический стек

### Рендеринг и 3D
| Слой | Технология | Обоснование |
|------|-----------|-------------|
| 3D-движок | **Three.js** (r160+) | Зрелая экосистема, отличная поддержка WebGL2/WebGPU, огромное комьюнити |
| Шейдеры | GLSL + **Three.js ShaderMaterial** | Кастомные эффекты для туманностей, звёзд, двигателей |
| Пост-обработка | Three.js EffectComposer | Bloom, HDR, motion blur, anti-aliasing |
| Физика (космос) | Собственный легковесный солвер | Ньютоновская механика + гравитация; cannon-es для стыковок и столкновений |
| Физика (атмосфера) | **cannon-es** | Для планетарных сцен с гравитацией |

### Бэкенд и сеть
| Слой | Технология | Обоснование |
|------|-----------|-------------|
| Сервер | **Node.js** + **uWebSockets.js** | Высокая производительность WebSocket,低кая latency |
| Авторизация | JWT + OAuth2 (Google/GitHub) | Безопасная сессионная модель |
| База данных | **PostgreSQL** + **Redis** | Игровое состояние (PG) + кеш/сессии/лидерборды (Redis) |
| Генерация мира | Детерминированные seed-based алгоритмы | Экономия трафика, бесконечная вселенная |
| State sync | Клиент-серверная модель с клиентским prediction | Плавный геймплей при любой latency |

### Клиентская архитектура
| Слой | Технология | Обоснование |
|------|-----------|-------------|
| Сборка | **Vite** | Быстрый HMR, tree-shaking, code-splitting |
| Язык | **TypeScript** (strict mode) | Безопасность типов, масштабируемость |
| Состояние | **Zustand** + Immer | Лёгкий state-менеджмент |
| ECS (опционально) | **bitECS** | Для сущностей мира (корабли, NPC, астероиды) |
| UI | **React** + Tailwind CSS | Интерфейсы кабины, HUD, меню |
| Звук | **Web Audio API** + Howler.js | 3D-позиционированный звук |
| Ассеты | glTF 2.0 | Стандарт для 3D-моделей |

## 4. Ключевые технические решения

### 4.1 Процедурная генерация вселенной

Вселенная генерируется детерминированно из мастер-seed (строка или число). Это позволяет:
- **Бесконечный мир** без хранения геометрии на сервере
- **Одинаковый мир** для всех игроков
- **Экономию трафика** — клиент генерирует систему на лету

```
Мастер-seed → Галактический seed → Системный seed → Планетарный seed
                                                      ├── Рельеф (Perlin noise)
                                                      ├── Биомы
                                                      ├── Ресурсы
                                                      ├── Станции
                                                      └── NPC-фракции
```

### 4.2 Лётная модель (Flight Model)

Реалистичная ньютоновская физика с assist-режимами:

| Режим | Описание |
|-------|----------|
| **Realistic** | Полная ньютоновская физика, 6 DoF, нет трения |
| **Flight Assist** | Компенсация вращения, автоматическое гашение боковой скорости |
| **Cruise** | Автоматическое поддержание скорости и направления |
| **Docking** | Медленное автоматическое сближение со станцией |

**Основные параметры корабля:**
- `thrust` — сила тяги главных двигателей
- `maneuveringThrust` — сила маневровых двигателей
- `rotationalSpeed` — угловая скорость (pitch/yaw/roll)
- `mass` — масса корабля (влияет на инерцию)
- `drag` — коэффициент сопротивления (в атмосфере)
- `maxSpeed` — максимальная скорость (в assist-режиме)
- `boostMultiplier` — множитель форсажа
- `boostEnergy` — энергия форсажа

### 4.3 Сетевая модель

**Модель: Client-Server с Client-Side Prediction**

```
Клиент (ввод) ──WebSocket──> Сервер (авторитативная симуляция)
     │                              │
     ├── Локальный prediction       ├── Валидация
     ├── Интерполяция чужих         ├── Экономика
     └── Реконсиляция ──────────────└── Broadcast другим игрокам
```

**Приоритеты сообщений:**
1. **Критические** (позиция, выстрелы, урон) — высокая частота, TCP-like надёжность
2. **Важные** (торговля, миссии, стыковка) — средняя частота, гарантированная доставка
3. **Фоновые** (цены, репутация, чат) — низкая частота

**Целевые показатели:**
- Tick rate сервера: 30 Hz
- Snapshot rate: 20 Hz
- Bandwidth на игрока: < 50 KB/s
- Максимальная latency для комфортной игры: 200 ms

### 4.4 Уровни детализации (LOD)

| Расстояние | Объект | Детализация |
|-----------|--------|-------------|
| 0–1 км | Корабль/станция | Полная модель, текстуры 2K |
| 1–10 км | Станция/астероид | Упрощённая модель |
| 10–1000 км | Планета | Impostor (рендер в текстуру) |
| 1000+ км | Планета | Точка/спрайт |
| Любое | Звёзды | Процедурный кубический скайбокс |

### 4.5 Производительность

**Целевые метрики (на среднем ПК):**
- 60 FPS в космосе (пустое пространство)
- 30+ FPS в密集ных сценах (станции, астероидные поля, бой)
- Первая загрузка < 10 секунд
- Переход между системами < 2 секунд

**Оптимизации:**
- Frustum culling (отсечение вне камеры)
- Object pooling (переиспользование объектов)
- Instanced rendering (для астероидов, обломков)
- Web Worker для генерации мира
- Adaptive quality (снижение качества при падении FPS)
- Code splitting (ленивая загрузка UI панелей)
- Asset streaming (подгрузка моделей по мере необходимости)

## 5. Игровые механики

### 5.1 Корабли и кастомизация

**Классы кораблей:**
| Класс | Роль | Отсеки | Масса |
|-------|------|--------|-------|
| Light Fighter | Бой, разведка | 4 | 10–30 т |
| Medium Freighter | Торговля, добыча | 8 | 50–150 т |
| Heavy Corvette | Бой, защита | 12 | 200–500 т |
| Explorer | Исследование | 10 | 30–80 т |

**Типы модулей:**
- **Оружие** — лазеры, плазма, ракеты, кинетика
- **Защита** — щиты, броня, ECM
- **Двигатели** — главные, маневровые, FTL
- **Утилиты** — сканеры, топливные баки, карго-отсеки, refinery, буровая установка
- **Специальные** — генератор помех, клоакинг, трекер-луч

### 5.2 Экономика

**Товары и ресурсы:**
- Руда (железо, титан, уран, ...)
- Промышленные товары (электроника, сплавы, компоненты)
- Потребительские товары (еда, медикаменты, предметы роскоши)
- Контрабанда (наркотики, оружие, запрещённые технологии)
- Топливо и боеприпасы

**Динамическое ценообразование:**
- Базовые цены зависят от типа экономики станции/планеты
- Дефицит и избыток меняют цены (±30%)
- События (война, блокада) могут кардинально менять рынок
- Торговые миссии игроков влияют на локальный рынок

**Типы экономик станций:**
- Agriculture, Mining, Industrial, High-Tech, Military, Tourism, Refinery

### 5.3 Боевая система

**Оружие:**
- **Энергетическое** — лазеры (точные, мгновенные), плазма (мощные, медленные)
- **Кинетическое** — автопушки, рельсотроны (против брони)
- **Взрывное** — ракеты, торпеды, мины
- **Специальное** — EMP, ионные пушки (против щитов), дроны

**Защита:**
- **Щиты** — регенерируют, слабы против кинетики
- **Броня** — не регенерирует, устойчива против всего
- **Манёвренность** — уклонение как главная защита

**Механика повреждений:**
- Повреждение модулей (двигатель, оружие, сканер могут быть выведены из строя)
- Утечка топлива/кислорода
- Перегрев оружия

### 5.4 Навигация

**Режимы перемещения:**
- **Обычный полёт** — до 500 м/с, для боя и манёвров у станций
- **Cruise** — до 10 км/с, для перемещений внутри системы
- **Jump / Warp** — FTL-прыжок между звёздными системами (требует топлива)
- **Supercruise** — до 0.1c, для межпланетных перелётов

### 5.5 Миссии и прогрессия

**Типы миссий:**
- Доставка груза
- Уничтожение цели (пираты, военные)
- Добыча ресурсов
- Разведка (сканирование аномалий)
- Спасение (спасательные капсулы, угнанные корабли)
- Курьерские (срочная доставка данных)
- Планетарные (доставка пассажиров, высадка)

**Прогрессия:**
- Репутация у фракций (открывает доступ к модулям, кораблям, миссиям)
- Ранги (торговый, боевой, исследовательский)
- Деньги → Улучшения → Более сложные миссии → Деньги

## 7. Визуальный стиль

### Референсы
- **Elite Dangerous** — чувство масштаба, реалистичная навигация, звуковой дизайн
- **No Man's Sky** — цветовая палитра, процедурные ландшафты
- **Freespace 2** — боёвка, ощущение скорости
- **Homeworld** — дизайн кораблей, небулы

### Принципы стиля
- **Stylized Realism** — реалистичное освещение (PBR), но с акцентом на читаемость геймплея
- **Цветовая кодировка** — враги красные, союзники зелёные, нейтралы серые/белые
- **Минималистичный UI** — диегетический интерфейс (приборы в кабине), минимум 2D-оверлеев
- **Космос — не чёрный** — туманности, галактический фон, цветное освещение от звёзд

## 9. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|------------|---------|-----------|
| Плохая производительность WebGL | Средняя | Высокое | Adaptive quality, fallback на упрощённый рендеринг |
| Сложность сетевого кода | Высокая | Высокое | Начать с PvE, мультиплеер — фаза 3 |
| Выгорание команды | Средняя | Критическое | Итеративная разработка, частые играбельные билды |
| Мало контента | Средняя | Среднее | Процедурная генерация + UGC инструменты |
| Низкий онлайн | Высокая | Среднее | Соло-режим как базовый, мультиплеер как бонус |
| Пиратство / читы | Низкая | Среднее | Серверная валидация, клиент — "глупый" рендерер |
