# AIATOR — Browser 3D Space Simulator

> Полная документация проекта для Claude Code и разработчиков.

## Быстрый старт

```bash
npm install
npm run dev      # Dev-сервер на localhost:5173
npm run build    # Production-сборка в dist/
```

## Описание игры

Полное описание концепции, геймплея и роадмапа: **[AIATOR.md](./AIATOR.md)**

## Фазы разработки

### Фаза 0 — Прототип ✅
Инициализация проекта, базовая 3D-сцена, лётная модель, одна звёздная система.

### Фаза 1 — Базовая игра ✅
Оружие, AI-пираты, станция, торговля, миссии, звуки, сохранения.

### Фаза 2 — Контент и глубина ✅
32 системы, FTL-прыжки, улучшения, добыча ресурсов, динамическая экономика, фракции, сюжетные миссии, генератор имён, саундтрек.

### Фаза 3 — Мультиплеер ❌ (не начата)
Серверная синхронизация, PvP, общий мир.

### Фаза 4 — Полировка и запуск ✅ (частично)
Адаптивное качество, мобильная версия, тач-управление, туннельный переход, атмосфера планет, детальная станция, умный AI, боковая панель UI, прямой DOM HUD.

## Деплой

Проект задеплоен на **Beget** (хостинг) по SSH:

```bash
# Сборка
npx vite build

# Очистка старых ассетов и деплой
ssh -i ~/.ssh/id_ed25519 dissemab@aiator.ru "rm -rf ~/aiator/public_html/assets/*"
scp -i ~/.ssh/id_ed25519 -r dist/* dissemab@aiator.ru:~/aiator/public_html/

# Сайт: https://aiator.ru/
```

**SSH-доступ:** `dissemab@aiator.ru` с ключом `~/.ssh/id_ed25519`
**Веб-рут:** `~/aiator/public_html/`
**Важно:** Перед каждым деплоем удалять старые ассеты (`assets/*`) — Vite генерирует хешированные имена, старые файлы не перезаписываются.

## Управление

Конфигурация клавиш: `src/config/controls.ts` — все бинды в одном месте.

### Клавиатура (десктоп)
| Клавиши | Действие |
|---------|----------|
| W/S/R/F | Pitch (R/F — сильный) |
| A/D | Yaw |
| Q/E | Roll |
| ,/. (Comma/Period) | Газ |
| Tab | Газ 100%/0% |
| Space | Форсаж |
| Z / Alt | Огонь |
| ЛКМ | Огонь (только pointer lock) |
| X / ? | Авто-aim (захват ближайшего врага) |
| M | Mining-луч |
| T | Станция (рынок) |
| 1/2/3 | Режим: Realistic/Assist/Cruise |
| J | FTL-прыжок (в Cruise) |
| N | Музыка вкл/выкл |
| B | Космическая пыль вкл/выкл |
| O | Карта системы |
| Стрелки + комбо | Pitch/Yaw/Roll (см. controls.ts) |
| Мышь | Pitch/Yaw (только pointer lock) |

### Тач-управление (мобильные)
| Зона | Действие |
|------|----------|
| Верхние ¾ экрана | Виртуальный джойстик: зажал → отвёл → вращение |
| Нижняя левая ¼ | Форсаж (держать) |
| Нижняя центральная ½ | Огонь (держать) |
| Нижняя правая ¼ | Газ (жест: зажал + вверх/вниз) |

## Ключевые архитектурные решения

### 1. HUD — прямой DOM, не React
Исторически HUD использовал Zustand → React, но были проблемы с обновлением (Immer v5, useSyncExternalStore). Финальное решение: **Engine.update() напрямую обновляет DOM-элементы по ID** (`document.getElementById('hud-speed').textContent = ...`). HUD-компонент рендерит только статичный HTML с ID. Никакого React-стейта для real-time данных.

### 2. Кастомный стор (не Zustand)
`ui/store/gameStore.ts` — свой легковесный стор на `useSyncExternalStore`. Используется только для редко меняющихся данных (рынок, миссии, модули, репутация). Для per-frame данных (скорость, газ) — прямой DOM (см. пункт 1).

### 3. Тач-управление
Реализовано в отдельном `useEffect` с `[mobile]` (не в `init()`). Раньше было в `init()` с `[]` deps, что ломалось при `mobile=false` на первом рендере. Touch-обработчики на `window`. Virtual joystick: запоминает начальную точку касания, скорость вращения пропорциональна расстоянию от start.

### 4. Физика (FlightModel)
- Ньютоновская механика: тяга → ускорение → скорость → позиция
- Субстепы 1/120с для стабильности (при 60fps = 2 субстепа)
- Drag: раздельный для линейного и углового движения
- 3 режима: Realistic (без drag), FlightAssist (демпфирование), Cruise (высокая скорость)
- Форсаж: `boostMultiplier=40`, drain пропорционален скорости, не работает с места
- Ограничение скорости: `maxSpeedAssist=30`, `maxSpeedCruise=200`

### 5. Варп-переход
При FTL-прыжке (J в Cruise):
1. Система переключается мгновенно (`switchSystem`)
2. Корабль отбрасывается на 200 000 ед. дальше по Z
3. За 5 секунд корабль плавно влетает в систему (ease-in-out)
4. Туннельный эффект: кольца частиц, вращение, 4 цветовые палитры
5. Спавн колец прекращается на 4с, последние улетают за экран
6. Эффект привязан к камере (не дёргается)

### 6. AI врагов
- 3 личности: aggressive (атакует с 350м), balanced (200м), cautious (120м)
- Стрельба с упреждением (учёт скорости игрока)
- Уклонение (dodge weaving) при здоровье <60%
- Экстренное бегство при здоровье <30%
- Респавн через 15 секунд после уничтожения всех

### 7. Масштаб системы
- Звезда: 8000-12000 ед. радиуса
- Планеты: 600-6500 ед., орбиты 80 000 – 580 000 ед.
- Корабль, враги, станция — оригинального размера (~5-10 ед.)
- Скорость корабля: 30 (Assist) / 200 (Cruise)

### 8. Планеты и кольца
- 4 типа: rocky, gas_giant, ice, lava
- Процедурные текстуры 512×512 (FBM-шум)
- Атмосфера: Fresnel-шейдер (AdditiveBlending)
- Кольца: RingGeometry + 1500 частиц-астероидов
- Спутники: 1-3 у газовых гигантов

### 9. Космическая пыль
- 400 частиц в мировом пространстве (не привязаны к кораблю)
- Спавн в сфере 10-70 ед. вокруг корабля
- Живут 5-12 секунд
- Возобновляются когда улетают дальше 80 ед.
- Эффект потока создаётся движением корабля сквозь частицы
- При поворотах — естественный сдвиг (частицы в мировом пространстве)
- B — вкл/выкл

### 10. Рендеринг
- Three.js r184
- Adaptive quality: снижение pixelRatio при FPS < 25/40 (только десктоп)
- Звёздное небо: 15 000 звёзд (PointsMaterial)
- Туманности: 4-8 на систему, многослойные спрайты с маской
- AdditiveBlending для всех эффектов (двигатели, взрывы, лазеры, варп)

## Состояние (State)

### Что хранится в localStorage (автосохранение каждые 10с)
- Кредиты, груз
- Прогресс миссий
- Сюжетный шаг

### Что НЕ сохраняется
- Позиция игрока (всегда старт у станции)
- Улучшения (сбрасываются)
- Репутация (сбрасывается)

## Известные проблемы и нюансы

1. **Кодировка файлов**: некоторые файлы (особенно GameCanvas.tsx, ShipController.ts) имеют нестандартные символы в комментариях. Редактирование через Tool Edit часто не работает. Использовать Python-скрипты или sed для правок.

2. **Двойные touch-обработчики**: в `init()` остался старый блок touch-кода, который не выполняется (mobile=false при первом рендере). Новый корректный код — в `useEffect([mobile])`.

3. **SCP при деплое**: `scp -r dist/*` не удаляет старые файлы. Всегда сначала `rm -rf ~/aiator/public_html/assets/*`.

4. **Мобильный лейаут**: определяется по `window.innerWidth < 768`. Боковая панель — полноэкранный оверлей по кнопке ☰.

5. **Pointer Lock на мобильных**: не поддерживается Safari iOS. Решение: `mobileMode = true` на ShipController обходит проверку `isPointerLockedState()`.

6. **Адаптивное качество**: отключено на мобильных (window.innerWidth < 768).
